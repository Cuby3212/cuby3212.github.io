## Español

Mi página personal con todas mis redes en un mismo sitio. Una alternativa de código abierto a servicios como Linktree, creada a partir de [LittleLink](https://littlelink.io).

Hecha con HTML, CSS y JavaScript y alojada en [GitHub Pages](https://pages.github.com/).

Gracias a [2Duoble](https://twitter.com/2Duoble) por ayudarme con algunos ajustes de diseño.

Código bajo [licencia MIT](LICENSE.md). Las imágenes y animaciones tienen sus propias licencias, recogidas en los [créditos](images/CREDITOS.md).

## English

My personal page with all my social links in one place. An open-source alternative to services like Linktree, built from [LittleLink](https://littlelink.io).

Made with HTML, CSS and JavaScript and hosted on [GitHub Pages](https://pages.github.com/).

Thanks to [2Duoble](https://twitter.com/2Duoble) for helping me with some design tweaks.

Code under the [MIT license](LICENSE.md). Images and animations have their own licenses, listed in the [credits](images/CREDITOS.md) (in Spanish).
